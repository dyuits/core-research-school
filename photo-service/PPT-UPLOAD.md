# 관리자 로그인과 수업 PPT

홈페이지에서 프로그램 → 수업 PPT → 관리자 로그인 · PPT 등록을 엽니다.
사진과 PPT 탭은 같은 관리자 로그인 세션을 사용합니다. 로그인은 저장소 연결 전에도 가능합니다.

차시 선택 후 PPT/PPTX를 여러 개 선택하고 개인정보·저작권 확인을 체크해 공개합니다.
파일당 50MB 이하이며 매크로 파일은 지원하지 않습니다. 원본 파일은 변환하지 않습니다.
업로드 SDK는 업로드 시에만 로드합니다. 관리자 인증 후 제한된 업로드 토큰을 발급해 Private Blob에 직접 전송하고,
서버에서 실제 PPT/ZIP 구조와 크기를 검증한 뒤 목록에 공개합니다. 다운로드는 공개 상태를 서버에서 확인합니다.
파일 크기·날짜·원본 파일명과 다운로드 버튼을 표시하며, 원본 SHA-256을 기록합니다.
공개 취소는 원본을 삭제하지 않습니다. 실패한 검증 파일은 해당 업로드만 제거합니다.

## 운영에 필요한 연결

Vercel 프로젝트 core-research-school-photos의 Storage에서 **Private Blob**을 만들고 프로젝트에 연결합니다.
BLOB_READ_WRITE_TOKEN이 Production에 설정되도록 연결한 뒤 재배포해야 합니다.
기존 ADMIN_PASSWORD_HASH, AUTH_SECRET, ALLOWED_ORIGINS는 유지합니다. 비밀값은 Git에 넣지 않습니다.
현재 연결 도구의 Blob 생성 권한이 거절되어 관리자가 대시보드에서 연결해야 합니다.
저장소가 없으면 로그인만 가능하고 업로드는 비활성 상태와 안내문으로 표시됩니다.

## 검증 및 제한

서버 테스트: 저장소 미연결 로그인, 잘못된 암호, 위조/만료 토큰, 비관리자 변경 차단,
사진 실제 변환, PPT/PPTX 형식 검사, 익명 원본 다운로드 바이트 일치, 공개 취소 후 접근 차단.
기존 PDF 메타데이터와 SHA-256 검증, TypeScript 검사, 정적 홈페이지 빌드를 수행합니다.
실제 Private Blob 업로드의 종단간 검증은 저장소 연결 후 필요합니다.
PPT를 브라우저에서 미리보는 기능은 제공하지 않으며 원본 다운로드를 지원합니다.
잘못된 업로드 후 페이지를 닫으면 비공개 미확정 원본이 남을 수 있으므로 저장소 사용량을 점검합니다.
