# 차시별 수업활동 사진 서비스

기존 GitHub Pages에서 공유할 사진을 Vercel Functions와 Private Blob 저장소에 영구 보관합니다. API는 `/api/photos`입니다.

환경변수: `ADMIN_PASSWORD_HASH`(scrypt salt:hash), `AUTH_SECRET`(32바이트 이상), `ALLOWED_ORIGINS=https://dyuits.github.io`, 프로젝트에 연결된 `BLOB_READ_WRITE_TOKEN` 또는 `BLOB_STORE_ID`.

프로그램·차시는 `lesson-map.json`에 한정합니다. 관리자 로그인 후 8시간 토큰으로 업로드·공개 취소를 요청합니다. 방문자는 공개된 사진만 볼 수 있습니다. 원본은 20MB 이하, 브라우저에서 최대 2048px·2MB로 줄이고 서버에서 실제 JPG/PNG/WebP 여부·픽셀 수를 검사해 WebP로 재인코딩합니다. EXIF와 GPS는 보존하지 않습니다. 식별 정보 및 공개 동의 확인은 교사가 직접 수행해야 하며 자동 얼굴 모자이크·식별정보 검출은 제공하지 않습니다.

각 사진은 고유 이미지와 메타데이터 객체로 저장됩니다. 업로드 중 메타데이터 저장에 실패하면 신규 이미지를 정리합니다. 공개 취소는 메타데이터의 published를 false로 변경하므로 비공개 원본은 보존됩니다. 다른 자료의 파일을 삭제하지 않습니다. 목록은 12개씩 불러오고 사진은 지연 로드합니다. 서비스 재배포 시에도 Blob 저장소의 데이터는 유지됩니다.

사진 탭의 로그아웃은 현재 브라우저의 토큰을 제거합니다. 이미 발급된 토큰은 8시간까지 유효하며, 즉시 모두 만료하려면 AUTH_SECRET을 교체해 재배포합니다. 로그인 암호는 자동 생성한 높은 엔트로피 값을 사용합니다. 계정별 권한·감사 이력·분산 로그인 시도 제한은 추후 확장 항목입니다.

검증: `npm ci && npm test && npm audit`. 테스트는 서버 인증/토큰 위조·만료, CORS, 프로그램·차시 유효성, 공개 확인 필수, SVG 거부, 사진 크기 조정·EXIF 제거, 별도 핸들러의 익명 열람, 공개 취소 후 접근 차단, 미연결 저장소 차단을 포함합니다. 테스트의 저장소 대역은 실제 운영 저장소가 아니며, 운영 시에는 Blob 연결 후 별도 업로드·익명 열람 검증이 필요합니다.
