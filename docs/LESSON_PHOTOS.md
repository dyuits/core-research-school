# 지도안 한 쪽 맞춤·차시별 사진 공유

PDF는 화면 가로뿐 아니라 미리보기 높이에 맞춰 축소하므로 기본 ‘한 쪽 맞춤’ 상태에서는 한 페이지 전체가 보입니다. 확대 후에는 ‘한 쪽 맞춤’을 누르면 원래 크기로 돌아갑니다.

## 구성

- 홈페이지의 프로그램 팝업에 ‘수업활동 사진’ 탭을 추가했습니다.
- 보고서의 실제 22차시 중 해당 프로그램에 속한 차시를 선택합니다.
- 공개 사진 목록은 관리자 로그인 없이 열람합니다.
- 관리자는 암호로 로그인해 사진을 여러 장 등록하고 공개를 취소할 수 있습니다.
- 공개 전 학생 식별 정보 제거·공개 동의를 확인해야 합니다.
- 브라우저에서 사진을 최대 2048px로 조정하고 서버가 실제 이미지 형식·픽셀·크기를 검증해 WebP로 다시 저장합니다. EXIF/GPS는 제거됩니다.
- 이미지와 설명은 Vercel Private Blob에 영구 저장하며 localStorage나 브라우저 메모리를 사진 저장소로 사용하지 않습니다.
- 비공개 저장소의 직접 URL을 공개하지 않으며 서버가 공개 상태를 확인한 뒤 사진을 전송합니다.

## 현재 배포 상태와 필요한 작업

Vercel 프로젝트 `core-research-school-photos`와 API를 만들고 배포했습니다. 프로젝트 주소:
https://vercel.com/dyuits/core-research-school-photos

현재 연결 앱의 Blob 생성 요청은 Vercel API에서 403 권한 부족으로 거부되었습니다. 별도 CLI 인증도 만료되어 자동 생성할 수 없었습니다. 실제 저장소 생성은 완료되지 않았습니다.

저장소 연결 전에는 홈페이지에서 등록 기능을 활성화하지 않습니다. 테스트에서 성공한 것으로 표시하거나 브라우저에만 사진을 저장하지 않습니다.

프로젝트 관리자 작업:

1. 위 프로젝트의 Storage에서 Blob 저장소를 생성합니다. Access는 **Private**을 선택합니다.
2. 저장소를 `core-research-school-photos` 프로젝트의 Production 환경에 연결합니다. 이름은 `core-school-lesson-photos`를 사용할 수 있습니다. 가능한 경우 서울(icn1) 리전을 선택합니다.
3. 이때 생성되는 BLOB_READ_WRITE_TOKEN 또는 BLOB_STORE_ID를 채팅·GitHub에 올리지 않습니다. 프로젝트 연결로 환경변수가 자동 설정되게 합니다.
4. 서비스 재배포 후 `/api/photos?action=status`가 `{"ready":true}`인지 확인합니다. 관리자 암호와 AUTH_SECRET은 이미 프로젝트의 민감 환경변수로 설정했습니다.
5. 실제 사진을 올려 로그아웃/다른 브라우저에서도 보이는지, 공개 취소 후 접근이 차단되는지 확인합니다. 저장소 연결 후 실제 운영 업로드 검증은 아직 수행하지 않았습니다.

서비스 API: https://core-research-school-photos-dyuits.vercel.app/api/photos
홈페이지의 연결 주소는 client/public/photo-service.json에 설정합니다.

운영 방법과 서버 보안·제약은 photo-service/README.md에 정리했습니다. 관리자 암호는 별도 로컬 안내 파일로 전달하며 소스코드와 Git에는 포함하지 않습니다.

## 검증

- 타입 검사, 기존 PDF 자료 테스트, 사진 서버 테스트, 전체 빌드 통과.
- 사진 서버 테스트: 익명 등록/공개 취소 차단, 관리자 암호 검사, 토큰 위조·만료, CORS, 올바른 프로그램·차시만 수락, 공개 확인 필수, SVG 거부, 크기 조정·EXIF 제거, 별도 핸들러에서 익명 열람, 공개 취소 후 접근 차단.
- 라이브 API는 저장소 미연결 상태 `ready:false`를 정상적으로 반환합니다.
- 브라우저에서 PDF canvas 높이가 미리보기 안에 들어오고 내부 scrollHeight와 clientHeight가 일치함을 확인했습니다.
