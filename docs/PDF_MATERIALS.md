# ver25 연구보고서 기준 PDF 수업자료 공개

홈페이지 제목은 제공된 연구보고서 PDF 2쪽의 공식 제목인 `AI·디지털 활용「CORE」프로그램을 통한 질문수용 중심 수업 실천과 AI 리터러시 함양`으로 수정했다. 브라우저 제목, 메타 설명, 메인 제목, 상단 안내와 푸터에 반영했다.

## 프로그램 편성

보고서 표 Ⅵ-4(p.29–31), 부록 8 및 실제 지도안을 우선했다. 이전 프로그램 데이터는 `client/src/data/archive/corePrograms.ts`에 보존했다.

|---|---|---|---|

정보는 지도안의 실제 두 주제(개인정보 보호, AI 정보 신뢰성)를 묶은 목록용 제목이다. 차시를 펼치면 지도안의 원래 주제를 표시한다. 독서의 영역은 첨부 지도안의 진로활동 표기를 사용했다(보고서 본문 표에는 자율, 부록 제목에는 진로로 표기되어 있음). 영어Ⅱ와 윤리와 사상은 전체 2차시 편성 중 공개수업 차시 중심의 지도안이므로, 별도 상세 내용이 없는 첫 차시 활동을 만들어 넣지 않았다.

기존 창체 음악 프로그램과 현대사회와 윤리의 공감지도 편성을 새 보고서의 CORE 수업으로 표시하지 않는다. 기존 생활기록부 예시 자료는 소스에 보존하며, 주제가 바뀐 윤리 및 새 정보 프로그램에는 기존 예시를 자동 재사용하지 않는다.

## 파일 저장 및 다운로드

제공된 HWPX 17개(지도안 10개, 별도 학생 활동지 7개)를 모두 PDF로 변환했다. 공개수업 과정안의 활동지·평가표는 해당 PDF 안에 함께 들어 있다. 원본 Desktop 파일은 수정하지 않았다. 연구보고서 전체와 HWPX 원본을 홈페이지에 업로드하지 않았다.

- 변환 도구: [rhwp v0.9.0](https://github.com/edwardkim/rhwp/releases/tag/v0.9.0), 로컬 CLI, 외부 변환 서버로 문서를 전송하지 않음.
- 도구 배포 아카이브 SHA-256을 릴리스 SHA256SUMS.txt와 대조했다.
- PDF는 `client/public/materials/`에 실제 파일로 저장하며 GitHub Pages의 정적 파일로 지속 배포된다.
- `pdfMaterials.ts`와 `materials/manifest.json`에 프로그램 연결, 자료 유형, 차시 범위, 파일 크기, 원본 이름, 변환 PDF SHA-256을 기록했다.
- `ProgramMaterials.tsx`의 링크는 Vite BASE_URL을 사용하여 `/core-research-school/materials/...pdf`를 가리킨다. 다운로드 속성에 한국어 파일명을 지정했다.
- 파일은 차시 범위 전체를 포함하는 통합 자료다. 개별 차시 PDF로 잘라진 것처럼 표시하지 않는다.
- 이 공개 작업은 Git에 포함된 정적 자료 배포이며 홈페이지 관리자 업로드 기능의 서버 배포와는 별개다. 기존 관리자 기능 개발 브랜치는 보존한다.

## 확인

총 17개 PDF, 72쪽을 다시 열고 전체 페이지를 PNG로 렌더링해 한글·표·이미지 표시를 검토했다. XML 원문과 PDF에서 추출한 영숫자·한글의 문자 빈도 대조는 모든 문서에서 100%였다. 이는 텍스트 순서나 한글 앱과의 조판 일치까지 증명하는 지표는 아니며, PDF 변환에 따라 일부 글꼴과 페이지 나눔이 달라질 수 있다.

`tsx --test tests/materials.test.ts`로 PDF 개수·파일명·크기·해시·프로그램 연결·22차시 누락 여부·보고서 제목 반영을 검사한다. 타입 검사와 GitHub Pages base 경로 빌드도 수행한다. 모바일 화면의 기존 프로그램 선택 탭이 500px로 고정되어 넘치는 문제를 함께 수정했다.
